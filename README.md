## 📌 Featured Projects

### ☁️ [Cloud Storage Ecosystem](https://github.com/pranavkhare11/express-file-preview-server)
**Node.js · Express.js · React · TypeScript · Aerospike · Docker** · 🚧 *In development*

A Google Drive–style cloud storage platform built on a virtual filesystem.
- Separates the folder hierarchy users see from physical storage, so files stay flat while folders nest freely.
- Copy, move, rename, delete and recursive operations run on metadata only, with zero-copy duplication.
- HTTP 206 byte-range streaming with FFmpeg moov-atom relocation for instant media playback.
- Dual-token HttpOnly JWT auth with Redis-backed session revocation.
- **Roadmap:** Photos- and Docs-style features on top of the same storage layer.

### 🛠️ Project Management Tracker
**Node.js · Hapi.js · TypeScript · MongoDB · Redis/Valkey**

Backend work on a revived 4+ year-old monorepo, done with a 6-student team.
- Migrated logging from `hapi-good` to `hapi-pino` (30+ lines of legacy code removed).
- Built a cache provider that switches between Redis and Valkey without app changes.
- Replaced phone-based OTP with Gmail OAuth2 and standardized TypeScript user schemas.

### 🔗 [Beacon Share](https://github.com/pranavkhare11/Beacon-Share)
**React · WebRTC · PeerJS · Vite**

Peer-to-peer file sharing where data goes directly between peers, with no intermediary server.
- Unique peer IDs, real-time transfer and progress tracking.
- Drag-and-drop React interface.
- Evolving into **Hybrid Storage**: P2P transfer plus optional ephemeral cloud storage (in progress).

### 💻 [GitHub Profiler](https://github.com/pranavkhare11/Github-Profiler)
A React and TypeScript application that uses the GitHub API to show profile statistics, contribution patterns, and repository information in an interactive dashboard.
